# Artefatos de demonstração

Esta pasta é reservada para arquivos liberados para distribuição, como o pacote ZIP da skill, exemplos autorizados de conversão e relatórios demonstrativos sem conteúdo confidencial.

O pacote ZIP inicial e os arquivos Markdown foram gerados na conversa de trabalho. A definição equivalente da skill está versionada em `SKILL.md` e a documentação está organizada nas demais pastas.

**Nota:** o template `land-template.dot` e o artigo-fonte anexado não foram versionados aqui. Antes de publicar esses arquivos, confirme direitos de redistribuição, permissões e eventual presença de dados confidenciais.
