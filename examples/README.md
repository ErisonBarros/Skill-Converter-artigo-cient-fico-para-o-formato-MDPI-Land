# Exemplos

Esta pasta pode conter exemplos mínimos de entrada/saída criados especificamente para demonstrar o fluxo da skill.

- Não incluir artigo de terceiros sem autorização ou licença compatível.
- Não publicar manuscritos com dados pessoais ou conteúdo confidencial.
- Preferir exemplos sintéticos que ilustrem a transformação estrutural sem simular resultados científicos reais.
- Se um exemplo usar dados reais, documentar fonte e permissões.
