# Templates

Esta pasta documenta como preparar o template editorial usado pela skill.

1. Obtenha a versão oficial mais recente do template *Land* (MDPI) e confira os termos de uso.
2. Coloque uma cópia local de `land-template.dot` ou DOCX nesta pasta somente se a licença permitir redistribuição.
3. Registre versão e data de obtenção num arquivo `TEMPLATE_VERSION.md`.
4. Não publique o template de terceiros sem verificar a licença. A skill pode referenciar um template mantido localmente sem que ele seja versionado no GitHub.

O template enviado durante a elaboração foi usado como referência, mas não foi incluído automaticamente no repositório.
